# 智慧城市 - Windows 桌面版

## 运行方式

### 方式一：一键启动（推荐）
双击运行 `智慧城市.bat` 文件，将自动启动本地服务器并在浏览器中打开游戏。

### 方式二：Electron 桌面应用
构建完成后，可在 `dist` 目录找到安装程序：
```bash
npm run dist:win
```

### 方式三：手动启动
1. 确保已安装 Node.js 18+
2. 打开命令行，进入项目目录
3. 运行以下命令：
```bash
npm install
npm start
```
4. 浏览器将自动打开 http://localhost:8686

## 系统要求

- Windows 10/11
- Node.js 18.0.0 或更高版本
- 现代浏览器（Chrome/Edge/Firefox）
- 支持 WebGL2 的显卡

## 功能特性

- 🏙️ 3D城市建造与仿真
- 📊 实时数据统计与分析
- 💰 财政预算与政策制定
- 🎯 灾害模拟与应急管理
- 📈 历史数据追踪

## 快捷键

| 按键 | 功能 |
|------|------|
| B | 财政预算 |
| E | 城市评估 |
| D | 灾害管理 |
| S | 存档/读档 |
| Esc | 关闭窗口 |
